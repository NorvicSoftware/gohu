# LARAVEL GOHU README

Laravel Gohu is a Visual Studio Code extension designed to help developers execute Eloquent and Query Builder queries directly within their Laravel applications.

This extension streamlines the development workflow by allowing you to run database queries without leaving the editor, making it easier to inspect data, test logic, and debug queries in real time.

Built for Laravel developers, it provides a fast and convenient way to interact with your application's data layer while staying focused on your code.
